بازی ضربه نهایی — سازنده: امین فخر عطایی

این پوشه پروژه اندروید بازی است و هنوز فایل APK کامپایل‌شده نیست.

ساخت APK:
1) Android Studio را نصب کنید.
2) پوشه ZarbeNahaeiAndroid را در Android Studio باز کنید.
3) صبر کنید Gradle Sync کامل شود.
4) از منوی Build گزینه Build Bundle(s) / APK(s) و سپس Build APK(s) را انتخاب کنید.
5) فایل APK از مسیر app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.

بازی داخل برنامه و بدون نیاز به اینترنت اجرا می‌شود.
برای انتشار عمومی، بهتر است نسخه Release را با کلید امضای شخصی بسازید.
